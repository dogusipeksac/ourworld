Third-Party Open-Source Voice Synthesis Licenses (Offline Pre-Rendered Audio Assets)
====================================================================================

All character voiceover audio files under Assets/GRIDROAM/Resources/Audio/Voice/
were pre-rendered offline using open-source, commercially permissible neural TTS models.

Turkish Voiceover Pack (Assets/GRIDROAM/Resources/Audio/Voice/tr/)
------------------------------------------------------------------
1. yazgi-tts-1 (https://huggingface.co/erkamk/yazgi-tts-1)
   - License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
   - Used voices: female-01, female-02, female-03, female-04, male-01, male-02, male-03, male-04

2. EMA Lightning (https://huggingface.co/canberkkkkkk/ema-lightning)
   - License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
   - Synthetic AI-generated Turkish voice (no real person's voice recording).

3. Antalia-2 Mini (https://huggingface.co/cloud0day3/antalia-mini)
   - License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
   - Synthetic AI-generated Turkish male voice (no real person's voice recording).

English Voiceover Pack (Assets/GRIDROAM/Resources/Audio/Voice/en/)
------------------------------------------------------------------
Pre-rendered offline using Piper TTS (MIT License, https://github.com/OHF-Voice/piper1-gpl / rhasspy/piper-voices)
with strictly Public Domain and CC0 voice datasets (no non-commercial models):

4. en_US-ljspeech-medium (LJ Speech Dataset — Public Domain)
5. en_US-kristin-medium (LibriVox — Public Domain)
6. en_US-bryce-medium (Public Domain)
7. en_US-joe-medium (OHF-Voice — CC0 1.0 Universal Public Domain Dedication)
8. en_US-john-medium (LibriVox — Public Domain)
9. en_US-norman-medium (LibriVox — Public Domain)

No third-party runtime Python code or GPL dependencies are bundled in the game binary;
only the rendered mono Vorbis-compressed audio assets are included in the application.
